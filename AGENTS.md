# AGENTS.md

FiscalCR: AI-powered, model-agnostic code review for GitHub pull requests. TypeScript (ESM), Node >= 20.

Agent navigation for this repo:

- [`.agents/AGENTS.md`](.agents/AGENTS.md) — router: which guide to read per task, source-of-truth hierarchy, non-negotiables.
- [`.agents/index.md`](.agents/index.md) — detailed, grep-friendly repo walkthrough (entry points, flows, testing map, change recipes).

## Non-negotiables

- Keep both entry points working: GitHub Action (`action/index.ts`) and self-hosted GitHub App (`src/index.ts`).
- `action/dist/` is generated by `pnpm build:action` (ncc). Never hand-edit it.
- `src/config/schema.ts` (zod) is the canonical config definition; `src/config/defaults.ts` must mirror it.
- Run focused tests (`pnpm test`, vitest) for behavioral changes and keep `pnpm lint` (`tsc --noEmit`) green.
